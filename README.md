# GUC CMS Downloader

A browser extension designed to enhance the download experience on the German University in Cairo's Content Management System (CMS). This tool streamlines the process of downloading course materials by adding bulk download capabilities and improving file organization.

## 🚀 Features

- **Smart File Organization**
  - Automatically renames files with meaningful, organized names
  - Preserves file extensions and content types
  - Handles special characters and long filenames

- **Bulk Download Options**
  - Download all materials from a specific week
  - Download all course files at once
  - Filter and download by content type:
    - Lectures
    - Tutorials
    - Projects
    - Assignments
    - Exercise Sheets
    - Solution Sheets

- **User Interface Enhancements**
  - Adds convenient download buttons for each week
  - Includes global download controls at the top of the course page
  - Clean and intuitive interface integration with CMS

## 🔧 Installation

   - Download the latest release from [Releases](https://github.com/Sirye8/guc-cms-downloader/releases)

## 🛠️ Technical Details

- **Browser Support**: Firefox (Primary)
- **Permissions Required**:
  - `activeTab`: For interacting with CMS pages
  - `downloads`: For managing file downloads
  - Limited to `cms.guc.edu.eg` domain

## 🔐 Privacy & Security

- Works exclusively on the GUC CMS domain
- No data collection or external communication
- All processing happens locally in your browser
- Open source code for full transparency
